# 常见功能问题

::: details 我要如何禁用指定附魔？

见[禁用]()功能。

:::
::: details 我要如何禁用附魔描述？

见[附魔描述]()功能。

:::
::: details 我要如何创建自定义附魔？

你不能这么做。我也不会添加这个功能。

:::
::: details 我能不能用这个插件修改/禁用原版附魔？

当前不在计划内。

:::
:::: details 能不能移除“过于昂贵！”的消息？

不能，这是游戏机制。

::: warning

使用“解除”这类限制的插件可能会引发漏洞或功能损坏，因为它们将玩家设置为了创造模式。

:::
