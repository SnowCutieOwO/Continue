# 从 V4 升级

自 v5 版本起，ExcellentEnchants 在 PaperMC 服务器上使用 Paper 注册表 API 来注册附魔，建议在**自定义命名空间**下进行注册。

::: warning

正因如此，为了同时支持 Spigot 与 Paper 服务端，插件代码有了许多**内部改动**。同样借此引入了大量**配置改动**。

:::

::: tip

无论如何，重新安装总是很不错的选择。

:::

## 命名空间

默认情况下所有附魔都使用 `excellentenchants` 命名空间。这意味着从 v4 迁移来的附魔会在服务器安装 v5 版本时**永久删除**，因为旧附魔的命名空间都是 `minecraft`。

如果需要在升级 v5 的同时保留附魔，你需要在开发环境中**预生成**所有新配置，并在投入生产前禁用[自定义命名空间](features.compatbility.md#命名空间)。

## 分布

全局分布与禁用附魔已移动至[对应的配置文件](features.disabling.md)。在投入生产环境前，请根据你的 v4 设置对其修改。

## 附魔设置

附魔设置**不会兼容**，你需要备份当前的 `/enchant/` 文件夹，并重新生成一份。之后，你就可以根据 v4 设置对其进行更改。

::: danger

不要尝试带着 `/enchants/` 中的 v4 附魔升级！

配置文件会被打乱，并且插件也会无法载入它们。

**后果自负。**

:::
