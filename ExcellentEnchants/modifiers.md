# 修饰符

在 ExcellentEnchants 的配置文件夹中，你可以看见多个“修饰符”设置。本页将会详细讲述它们的功能和使用方法。

**修饰符设置：**

* **基数（Base）** - 修饰符的初始值。
* **每级（Per Level）** - 每级附魔提供的增益数值。
* **行为（Action）** - 为**基数**和**每级**值进行指定的计算操作。
  可填入：`ADD`（叠加）、`MULTIPLY`（相乘）。

假设如下修饰符会应用至某个 V 级附魔：

* **基数**：5
* **每级**：0.5
* **行为**：ADD

则结果为 $result = 1.0 + (0.5 \times 5) = 1.0 + 2.5 = 3.5$
