# 充能

充能附魔是一种，使得附魔使用次数有限（能量条）的功能。效果次数（能量条）用尽时，玩家需要用“燃料”物品为其充能。

::: tip

附魔的充能上限随等级动态变化。

:::

## 我要怎么使用？

1. 在 **config.yml** 的 `Charges` -> `Enabled: true` 部分启用本功能。
2. 使用命令 `/eechants reload` 重载插件。
3. 充能设置现在会出现在 `/enchants/` 文件夹下。

## 燃料

默认情况下，所有附魔均使用青金石充能。

你可以在对应的配置文件中设置不同的燃料物品。

::: tip

燃料物品可以完全自定义，包括名称、描述、自定义模型数据等。

:::

## 充能

只需在铁砧中将物品与燃料结合即可为附魔充能。

每次充能会消耗 *1 级经验*。
