# ✅ 插件需求

## Java 版本

* 最低要求：**Java 16+**
* <font color="red">推荐</font>使用 **Java 17+**。插件也支持更高的版本，但插件基于 **Java 16** 编写，理论上只需 Java 16+ 即可。

## 服务器核心

* <font color="red">推荐</font>使用 **Paper** 及其下游分支。在插件检测到你使用的核心为 Paper 时，它会自动启用某些仅对 Paper 开放的功能，其中部分还可以提升性能。
* 本插件同样支持 **Folia**。请注意：Folia 支持<font color="red">仍处于早期阶段</font>，可能包含在之后的发行版中，也可能会被移除。不保证一定支持。

## 服务器版本

|版本|兼容|官方技术支持|
|---|---|---|
|**低于 1.14**|❌|❌|
|**1.14 \~ 1.20.4**|❓<br>插件兼容这些版本，但这些版本出现的问题将不会得到修复。|❌|
|**高于1.20.5**|✅<br>推荐使用 **1.21.5+**，使用体验更佳。|✅|

* 如果在使用某个版本时遇到问题，<font color="red">请加入我们的 Discord 聊天群组</font>。

## 支持自定义货币的经济插件

* **UltimateShop** 只是一个商店插件，并不具备任何经济功能。如果你想要服务器拥有自定义经济功能，请自行寻找合适的经济插件。另外，**Vault** 不是经济插件，它只是大部分经济插件的接口。<font color="red">在服务器上安装 Vault 之后，同样需要安装一个支持它的经济插件。</font>
