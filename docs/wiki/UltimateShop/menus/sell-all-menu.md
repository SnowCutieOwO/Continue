# 🛒 全部出售菜单

## 配置文件

你可以在 `config.yml` 文件中找到关于设置全部出售菜单的配置选项。你只可以创建 1 个全部出售菜单。

```yaml
menu:
  sell-all:
    size: 54
    title: '{lang}'
    black-slots: []
```

* size: 菜单大小。仅支持填入如下数字：**9、18、27、36、45、54**。
* title: 菜单界面的标题。
* black-slots: 设置哪些槽位不能放置物品，例如： `[0, 1, 2, 3]`.

## 全部出售

关闭这个菜单就会出售你放置在这个菜单内的全部物品，如果物品没有被出售，则会返还。此菜单同样受 `config.yml` 文件中的 `sell.max-amount` 选项限制最大出售物品数量，默认情况下，该值是 `128`。

## 打开全部出售菜单

你可以通过指令 `/shop sellall` 打开全部出售菜单。该指令需要 `ultimateshop.sellall` 权限节点。
