# 特殊纹理文件类型

除了默认格式（`xcount` 乘以 `ycount` 的平面网格），Dynmap 还支持一些特殊格式的纹理文件。目前定义类型包括如下：

* `GRID` - 默认类型，对应 `xcount` 单位宽，`ycount` 单位高的方形纹理。每个纹理边长都需要为 2 的次幂。纹理的序号从左上角（`index=0`）逐渐移动到第一行右侧（为 `index=<xcount>-1`），然后转到下一行从左往右数第一格（`index=<xcount>`），依此类推。
* `CHEST` - 应用于小型箱子的纹理排版格式。序号值为：
  * `0`：箱子顶部
  * `1`：箱子左面
  * `2`：箱子右面
  * `3`：箱子正面
  * `4`：箱子背面
  * `5`：箱子底面
* `BITCHEST` - 应用于大型箱子的纹理排版格式。序号值为：
  * `0`：箱子顶部 - 左半部分
  * `1`：箱子顶部 - 右半部分
  * `2`：箱子前面 - 左半部分
  * `3`：箱子前面 - 右半部分
  * `4`：箱子左面
  * `5`：箱子右面
  * `6`：箱子背面 - 左半部分
  * `7`：箱子背面 - 右半部分
  * `8`：箱子底面 - 左半部分
  * `9`：箱子底面 - 右半部分
* `SIGN` - 应用于告示牌的纹理排版格式。序号值为：
  * `0`：贴墙告示牌正面
  * `1`：贴墙告示牌背面
  * `2`：贴墙告示牌顶面
  * `3`：贴墙告示牌底面
  * `4`：贴墙告示牌左面
  * `5`：贴墙告示牌右面
  * `6`：立柱告示牌正面
  * `7`：立柱告示牌背面
  * `8`：立柱告示牌左面
  * `9`：立柱告示牌右面
* `SKIN` - 应用于玩家（或其他人形实体皮肤）的纹理排版格式。序号值为：
  * `0`：头部正面
  * `1`：头部左面
  * `2`：头部右面
  * `3`：头部背面
  * `4`：头部顶面
  * `5`：头部底面
* `CUSTOM` - 这个格式更加灵活，允许提取任意矩形纹理用作索引纹理。`<xcount>` 与 `<ycount>` 值用于检测纹理图片的比例（假设正常纹理长宽为 `<xcount>` 及 `<ycount>` 的 16 整数倍）。`texturefile` 属性定义需要为每个纹理索引包含至少一个 `tile<数字>=` 属性（`数字` 为 0、1、2 等）。字段对应值如下：
  * tile=:/:

或者，可以这样：

``` txt
  tile<数字>=<X 轴源偏移>:<Y 轴源偏移>/<X 轴>:<Y 轴>/<X 轴目标偏移>:<Y 轴目标偏移>
```

参数解释：

* `<X 轴源偏移>` 为文件内左上角纹理的 X 轴起始点，单位为比例像素
* `<Y 轴源偏移>` 为文件内左上角纹理的 Y 轴起始点，单位为比例像素
* `<X 轴>`：为文件内的水平纹理，单位为比例像素
* `<Y 轴>`：为文件内的垂直纹理，单位为比例像素
* `<X 轴目标偏移>`：为目标文件内的左上角纹理的 X 轴起始点（默认为 0），单位为比例像素
* `<Y 轴目标偏移>`：为目标文件内的左上角纹理的 Y 轴起始点（默认为 0），单位为比例像素
