# 体积模型的方块定义

基于体积模型的方块可能会拥有复杂的形状，且可能使用与简单实心方块与长方模型一样的纹理定义。对体积模型的纹理应用与简单方块或长方模型相同——每个体块的六面纹理都会应用到模型内的子块，同时纹理缩放到整个块面的大小。因此，纹理定义文件中的纹理定义与简单实心方块和长方模型相同。

体积模型首先基于提供的 `scale` 属性，将完整方块切为子块，再进行定义——使得方块可以表示为 `scale` \* `scale` \* `scale` 的小方块。之后，每个子块根据模型的设置占据或填充空间，使其表现为按特定顺序排列组合。更多细节请见“定义体积模型”。体积模型的示例即为漏斗：

``` txt
    block:id=154,data=*,scale=16
    layer:0,1,2,3
    ----------------
    ----------------
    ----------------
    ----------------
    ----------------
    ----------------
    ------****------
    ------****------
    ------****------
    ------****------
    ----------------
    ----------------
    ----------------
    ----------------
    ----------------
    ----------------
    layer:4,5,6,7,8,9
    ----------------
    ----------------
    ----------------
    ----------------
    ----********----
    ----********----
    ----********----
    ----********----
    ----********----
    ----********----
    ----********----
    ----********----
    ----------------
    ----------------
    ----------------
    ----------------
    layer:10
    ****************
    ****************
    ****************
    ****************
    ****************
    ****************
    ****************
    ****************
    ****************
    ****************
    ****************
    ****************
    ****************
    ****************
    ****************
    ****************
    layer:11,12,13,14,15
    ****************
    ****************
    **------------**
    **------------**
    **------------**
    **------------**
    **------------**
    **------------**
    **------------**
    **------------**
    **------------**
    **------------**
    **------------**
    **------------**
    ****************
    ****************
```

模型定义后，纹理引用与简单实心方块相同——更多细节请见“[定义简单方块](defining-a-simple-block.md)”。对于漏斗方块，它的定义则为：

``` txt
  block:id=154,data=*,allsides=0:hopper_outside,top=0:hopper_inside,bottom=0:hopper_outside,stdrot=true
```
