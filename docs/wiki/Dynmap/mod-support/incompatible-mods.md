# 不兼容模组

与 blockscan 不兼容，且会导致所有模组模型不渲染的模组：

* [暮色森林](https://www.mcmod.cn/class/61.html) 1.16.5-4.0.870
* [EnviroCore](https://www.mcmod.cn/class/3270.html) 1.16.5-3.0.9.3

可能会使得服务器崩溃的模组：

* 目前尚无。

让方块渲染的方法：

从 renderdata 文件夹下移除如下文件：

* twilightforest-models.txt
* twilightforest-texture.txt
* envirocore-models.txt
* envirocore-texture.txt
