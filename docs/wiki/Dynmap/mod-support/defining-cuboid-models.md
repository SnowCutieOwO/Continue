# 定义长方体模型

长方体是最简单的一类模型。它们代表着一类在一或多个轴向上被切割过的方块。在一般方块中的例子就是台阶（上半或下半（垂直的）Y 轴被削去了 0.5 格），雪片（对于不同层数的积雪，Y 轴被不同程度地削去）以及压力板（三轴均被切削）。

长方体仍然是一个六面模型，因此纹理的定义与应用仍与简单实心方块相同：纹理在各轴上按大小进行同样切割即可。每层纹理的处理方式类似于将纹理应用于未经切割的模型面，因此它只会显示切割后对应面积的纹理。

定义立方体模型需要用到 `boxblock` 选项，其参数设置包含如下：

* `id` - 使用此模型的方块 ID。需要指定至少一个 `id` 属性，但数量不限——允许同一模型用在多个方块。见“方块 ID 数字”了解如何指定方块 ID 数字的详情。
* `data` - 对模型应用的方块增加匹配数据值的要求。默认值 `data=*` 表示匹配所有对应 `id` 属性下带有任何数据值的方块。否则，只匹配一或多个 `data=数字` 元数据的方块。
* `xmin` - 决定了方块 X 轴切割的最小值：设置后，方块的 X 轴将会从给定值处起始（默认值则为 0.0，即不偏移）。
* `xmax` - 决定了方块 X 轴切割的最大值：设置后，方块的 X 轴将会在给定值处结束（默认值则为 0.0，即不偏移）。
* `ymin` - 决定了方块 Y 轴切割的最小值：设置后，方块的 Y 轴将会从给定值处起始（默认值则为 0.0，即不偏移）。
* `ymax` - 决定了方块 Y 轴切割的最大值：设置后，方块的 Y 轴将会在给定值处结束（默认值则为 0.0，即不偏移）。
* `zmin` - 决定了方块 Z 轴切割的最小值：设置后，方块的 Z 轴将会从给定值处起始（默认值则为 0.0，即不偏移）。
* `zmax` - 决定了方块 Z 轴切割的最大值：设置后，方块的 Z 轴将会在给定值处结束（默认值则为 0.0，即不偏移）。

所有削除设置属性都是可选的——默认值表示三轴上完整方块的大小：0.0 最小，1.0 最大。方块被限制在 0.0 与 1.0 的值之间（含）。给定轴的最小切割值必须小于等于同轴的最大切割值。

## 示例

原版的阳光传感器：长宽完整，高则为 0.375（游戏内表现为 6 像素高）

``` txt
  boxblock:id=151,data=*,ymax=0.375
```

地毯方块：长宽完整，高则为 0.0625（游戏内表现为 1 像素高）

``` txt
  boxblock:id=171,data=*,ymax=0.0625
```

雪片：长宽完整，高度视元数据设置的层数而定

``` txt
  boxblock:id=78,data=0,data=8,ymax=0.125
  boxblock:id=78,data=1,data=9,ymax=0.25
  boxblock:id=78,data=2,data=10,ymax=0.375
  boxblock:id=78,data=3,data=11,ymax=0.5
  boxblock:id=78,data=4,data=12,ymax=0.625
  boxblock:id=78,data=5,data=13,ymax=0.75
  boxblock:id=78,data=6,data=14,ymax=0.875
```

压力板（四个不同的方块 ID，使用同一模型）：三轴均有削除（水平位于 0.0625 到 0.9275 之间，垂直则为 0.0 到 0.0625）

``` txt
  boxblock:id=72,id=70,id=147,id=148,data=*,xmin=0.0625,xmax=0.9275,ymax=0.0625,zmin=0.0625,zmax=0.9275
```

按钮方块（不同方块 ID，随不同放置朝向有不同的元数据值）：三轴均有削除

``` txt
  boxblock:id=77,id=143,data=1,data=9,xmax=0.125,ymin=0.375,ymax=0.625,zmin=0.3125,zmax=0.6875
  boxblock:id=77,id=143,data=2,data=10,xmin=0.875,ymin=0.375,ymax=0.625,zmin=0.3125,zmax=0.6875
  boxblock:id=77,id=143,data=3,data=11,zmax=0.125,ymin=0.375,ymax=0.625,xmin=0.3125,xmax=0.6875
  boxblock:id=77,id=143,data=4,data=12,zmin=0.875,ymin=0.375,ymax=0.625,xmin=0.3125,xmax=0.6875
```
