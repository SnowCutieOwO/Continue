# 插件特色

可以在浏览器中查看服务器的实时地图，且界面类似谷歌地图。通过 Dynmap 内置的网页服务器，开箱即可投入使用，同时它也可以与在 Apache 等平台上运行的其他网站一并使用。Dynmap 可使用不同的渲染器绘制地图，部分注重西性能，而其他的则注重细节。

组件允许你添加/移除功能，使得 Dynmap 更符合你的需求。通过组件，Dynmap 可以支持聊天气泡、网页与游戏内实时同步聊天，以及可配置的标记、区域及线条等。

## 插件特色

* 全局及分世界均高度可配置。
* 实时更新：与世界实时同步更新，浏览器打开后持续显示地图变动。
* 玩家会在地图上以其头像显示。
* 聊天消息在地图上可见（气泡或聊天框）。
* 浏览地图的玩家可与服务器内玩家聊天。
* 地图会显示当前 Minecraft 时间与天气。
* WorldGuard、Residence、Towny 与 Factions 插件的区域会显示在地图上（通过各自的 Dynmap-* 拓展插件）。
