# 存储安装

Dynmap 需要大量空间存储地图图块、标记点等数据。默认情况下，存储功能由本地文件系统提供，另外支持其他的存储方法。目前插件支持如下：

* 文件系统存储 - 默认选项，最简单的选择。
* MySQL/MariaDB 存储 - 使用 MySQL 或 MariaDB 数据库存储地图数据。可以带来一些优势 - 允许网页服务器与 MC 服务器分离，架设在不同的电脑/虚拟机/容器中。
* PostgreSQL 存储 - 使用 PostgreSQL 数据库存储地图数据。可以带来一些优势 - 允许网页服务器与 MC 服务器分离，架设在不同的电脑/虚拟机/容器中。
* SQLite 存储 - 使用最简单的 SQLite 数据库存储地图数据。与文件系统存储类型（本地运行，且与 Minecraft 进程绑定），但可以降低单文件的占用。
* AWS S3 对象存储 - 既可以用作存储，也可以用作外置网页服务器，允许地图数据在 AWS S3“存储桶”中的推送及拉取，适用于需要大型本地存储和/或额外内置网页服务器 TCP/IP 端口，却受限于托管环境而无法获得的服务器。
