# 插件安装

本页以简洁明了的方式讲述了如何安装 Dynamp，同时将其开放给玩家。社区贡献的视频教程请在本页末查询。[^1]

## 前言

* 本页假设你是 Minecraft 服主，使用的版本及核心种类均符合本插件的安装要求。所有支持的版本及核心类型可以在[主页](../../home.md)找到。
* 本页假设你已拥有对操作系统或映射方式的相关知识，能够安装插件并开放/请求端口。
* 本页假设你使用的 Dynmap 是官方发布的最新版本。[主页](../../home.md)可以找到下载链接。

## 开始

1. **关闭你的 Minecraft 服务器。** 你可能想要用诸如 `/reload` 或 `/dynmap reload` ...的命令。但**请不要**使用 `/reload` 命令，因为它会搞坏很多东西，并且这些命令自其出现就饱受诟病。如果你改动了配置文件，你也可以重启服务器来应用改动。希望未来的版本中 `/dynmap reload` 命令会更加稳定。
2. **下载 Dynmap 插件。**一般的下载地址，如 [CurseForge 上的模组版本](https://www.curseforge.com/minecraft/mc-mods/dynmapforge)，[Spigot](https://www.spigotmc.org/resources/dynmap.274/)、[Bukkit](https://dev.bukkit.org/projects/dynmap)，或是 [Github 发行版页面](https://github.com/webbukkit/dynmap/releases)。
3. **添加 Dynmap 插件。** 将下载好的 Dynmap-.jar 放入服务器的 `/plugins/` 或 `/mods/` 文件夹中。
4. **启动服务器。**
5. **验证是否安装。** 插件文件夹会出现一个 `dynmap` 文件夹，其内有一个 `configuration.txt` 文件。这个文件包含了插件的绝大部分设置，但可能对你而言有些复杂，并且有些部分的配置可能你自始至终都不需要改动。这个文件的相关文档可以在 [Configuration.txt](https://github.com/webbukkit/dynmap/wiki/Configuration.txt) 章节找到。
6. **端口转发。** 大部分用户会败在这一步，我将这部分按服务器类型分为几个小步骤，以便你更好地阅读。
  1. **面板服** 大部分服务器托管商只允许一个端口（用于 Minecraft 服务器），但允许用户“请求”开放其他端口。一般可以提交工单解决，但你需要根据服务器提供商的规则自行研究。如果他们允许你选择，你可以使用 8123，这是 Dynmap 的默认端口。但通常情况下你获得的是随机端口。例如，你的服务器托管商给你开放了 7229 端口。这时，你就要前往 configuration.txt，将第 322 行的 `webserver-port: 8123` 改成 `webserver-port: 7229`。请确保在改动之后重启服务器，之后你可以通过 `http://<服务器 IP>:7229` 打开网页地图。假如你的服务器 IP 是 `192.192.192.192:25565`，那么你在浏览器输入的地址就是 `http://192.192.192.192:7229`。这样 Dynmap 的网页服务器就会运行在这个端口上，你可以阅读下一步教程了。
  2. **VPS** VPS 提供商数量繁多，“标准”各有区别，难以在本章节详细讲述 Minecraft 服务器的相关信息。如果你使用的是共享 IP 地址，你可以联系服务器提供商为你开放一个端口。如果你使用的是独立 IP 地址，只需保持默认设置，打开浏览器并输入地址 `http://<服务器 IP>:8123` 即可浏览。如果你的共享 VPS 有多个端口，只需按上文所述修改配置文件并在浏览器中按对应链接打开即可。当你能够正常访问网页地图时，你就可以浏览下一步。
  3. **自托管** 这种情况下你通常拥有的是独立 IP。如果你没有，你如何搭建 Minecraft 服务器？希望你还记得如何转发 Minecraft 服务器的方法。如果你不幸忘记，你可以在[这里](https://portforward.com/)找到相关教程。打开端口并确保能够通过网址 `http://<服务器 IP>:8123` 连上网页服务器即可。再强调一次，如果你的服务器 IP 是 `192.192.192.192:255565`，那么服务器网页地图的地址是 `http://192.192.192.192.8123`。当你能够正常访问网页地图时，你就可以浏览下一步。
  4. **遇到问题？** 别担心，你不是第一个在这节骨眼上碰到问题的人。网络搭建确实恼人，但我对其有着自己的理解。首先，检查你的服务器日志并确保 Dynmap 正常载入。如果它能够正常启动，服务器日志里应该会显示这样一行文字： `[dynmap] Web server started on address 0.0.0.0:8123`。如果出现错误，很有可能是端口已经被占用，或者操作系统上的防火墙出现了问题。这些问题因篇幅过长难以概括在本章教程，因此建议联系 Dynmap 团队获取帮助。如果 Dynmap 正常启动，且日志里没有相关报错，这有可能是端口转发出现了问题，或者防火墙出现了问题。首先，前往 [canyouseeme.org](https://www.canyouseeme.org/)，输入你的 IP 地址与端口号。它会检查端口号是否开放。有关这个网站的含义、操作方法和潜在风险可在[这里](https://portforward.com/)浏览。如果你还有其他问题，或还是不能成功开放端口，请联系 Dynmap 团队获取帮助。
