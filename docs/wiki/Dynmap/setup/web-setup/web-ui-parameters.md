# 网页界面参数

用于打开网页界面的链接支持一些参数，可以用来覆盖默认参数。可以让网页地图自动翻到某个世界的地图，或者指定缩放大小，以及聚焦在指定世界的位置。

参数以键值对的形式提供，每个参数都按如下格式出现：

``` txt
属性=值
```

基本的链接末尾会有一个英文问号 `?`，每个参数之间都由英文和号 `&` 隔开。因此网页地图的默认网址为：

``` txt
http://mygreatserver:8123/
```

之后，让网页地图选择名为 `fred` 的世界，显示 `surface` 类型的地图，格式则为：

``` txt
http://mygreatserver:8123/?worldname=fred&mapname=surface
```

如果你使用的是外置网页服务器，那么格式是一样的——只需在末尾加上 `?`，然后加上 `&` 隔开的参数即可：

``` txt
http://mycoolapacheserver.com/dynmap?worldname=fred&mapname=surface
```

可填入的参数如下：
* `worldname` - 指定选中世界的名称（不是标题）。不填则选中定义的首个世界（除非 `configuration.txt` 中设置了 `defaultworld`，那么显示这个设置对应的世界）。
* `mapname` - 指定地图类型的名称（不是标题）。不填则选中定义的首个地图（除非 `configuration.txt` 中设置了 `defaultmap`，那么显示这个设置对应的地图）。
* `zoom` - 指定缩放大小（`0` 为最小缩放）。不填则使用 `0`（除非 `configuration.txt` 中设置了 `defaultzoom`）。
* `x` - 决定了地图界面（对应世界）聚焦的 X 轴坐标。不填则使用指定世界 `center` 设置的对应坐标（通常为 `0`）。
* `y` - 决定了地图界面（对应世界）聚焦的 Y 轴坐标。不填则使用指定世界 `center` 设置的对应坐标（通常为 `0`）。
* `z` - 决定了地图界面（对应世界）聚焦的 Z 轴坐标。不填则使用指定世界 `center` 设置的对应坐标（通常为 `0`）。
* `nopanel` - 若存在且设置为 true，则隐藏侧边栏菜单。
* `chatname` - 若存在且设置内容，则在聊天栏中以此作为发送者名称。若开启 `trustclientname` 则只会被内置网页服务器接受，除非在聊天组件中将 `allowurlname` 设置开启。仅 0.28 之后的版本支持。
* `playername` - 若存在且设置为对应（在线或稍后在线）玩家的名称，则网页界面会尝试寻找并聚焦玩家的位置。
* `hidechat` - 若存在且设置为 true，网页界面会禁用所有聊天输入输出组件（聊天气泡、输入框以及聊天栏本身）。
* `nogui` - 若存在且设置为 true，网页界面会禁用所有控制方式、面板等内容，只展示地图本身。
* `nocompass` - 若存在且设置为 true，则隐藏指南针组件（v2.2-alpha-1 后）
