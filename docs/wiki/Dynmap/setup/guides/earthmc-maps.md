# EarthMC 地图

EarthMC 的地图与 Dynmap 有许多已知的兼容性问题：例如渲染不完整，只渲染玩家探索过的区域，或者不渲染树叶等植被。这是地图的制作方式导致的，而不是 Dynmap 本身有问题，不过好在这里有解决方法。

1. 下载 WorldBorder 插件：https://www.spigotmc.org/resources/worldborder.60905/
2. 暂停地图显示：`/dynmap pause all`
3. 设置世界边界半径与中心：`/wb [世界名称] set [X 轴半径] [Z 轴半径] {X} {Z}`
  * `[世界名称]` 为需要设置边界的名称
  * `[X 轴半径]` 为世界的水平半径
  * `[Z 轴半径]` 为世界的垂直半径
  * `{X}` 为世界的水平中心点
  * `{Z}` 为世界的垂直中心点
4. 强制 WorldBorder 开始执行任务：`/wb [世界名称] fill [频率] [余量] [强制]`
  * `[世界名称]` 为需要预生成的世界名称
  * `[频率]` 为每秒生成多少区块，默认为 20。警告：设置太高会导致卡顿。
  * `[余量]` 为在世界边界之外生成多少区块，确保玩家抵达世界边界时还能看见边界以外的区块。默认为 208，不过对于 EarthMC 地图，建议将其设置为 0。
  * `[强制]` 必须设置为 true。
5. 等待预生成完毕。
  * 完成之后，输入命令取消暂停：`/dynmap pause none`，可能需要使用命令 `/dynmap fullrender [世界名称]` 重新渲染一次地图才会生效。
