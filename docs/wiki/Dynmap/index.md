# 前言

2026/7/29 23:58

Dynmap 是一款老牌的网页地图插件，兼容性好，联动插件/模组等数量众多，提供平面及三轴渲染方式，还为不在服务器里的玩家提供了远程聊天功能，是一款不可多得的地图神器。

本维基耗时六个月，基于原有文章与译者资料对原文缺损内容进行删改补充。虽历时许久呕心沥血，恐仍有错漏之处，望读者耐心指出。
