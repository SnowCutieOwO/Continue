# FenceWallBlockRenderer 类

FenceWallBlockRenderer 类用于渲染与原版栅栏/墙行为类似的方块。这些方块会与相同 ID 及任意固体方块相连，但也可以通过 `link<数字>` 设置为其他方块。

## 属性

* `type` - 使用的模型类型。有效值包括 `fence` 和 `wall`，前者表示栅栏，后者表示墙。默认为 `fence`。
* `link<数字>` - 允许与（除自身及所有固体方块外的）特定方块相连。可以指定任意连续的数字，且值从零开始（`link0=数字`、`link1=数字`，依此类推。）

## 需要纹理的补丁

* `patch0` - 用于模型所有面的纹理（除顶底面）
* `patch1` - 用于模型所有顶面的纹理
* `patch2` - 用于模型所有底面的纹理
