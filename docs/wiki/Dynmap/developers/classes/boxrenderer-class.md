# BoxRenderer 类

BoxRenderer 类是一个简单的着色器，用于创建正常实心方块（仅纹理有差别），但在 XYZ 轴上有缩减。与大部分自定义着色器不同的是，应用于模型的纹理设置与一般的实心方块相同。注意：这是用于实现立方体模型的自定义着色器。

## 属性

* `xmin` - 决定了方块 X 轴切割的最小值：设置后，方块的 X 轴将会从给定值处起始（默认值则为 0.0，即不偏移）。
* `xmax` - 决定了方块 X 轴切割的最大值：设置后，方块的 X 轴将会在给定值处结束（默认值则为 0.0，即不偏移）。
* `ymin` - 决定了方块 Y 轴切割的最小值：设置后，方块的 Y 轴将会从给定值处起始（默认值则为 0.0，即不偏移）。
* `ymax` - 决定了方块 Y 轴切割的最大值：设置后，方块的 Y 轴将会在给定值处结束（默认值则为 0.0，即不偏移）。
* `zmin` - 决定了方块 Z 轴切割的最小值：设置后，方块的 Z 轴将会从给定值处起始（默认值则为 0.0，即不偏移）。
* `zmax` - 决定了方块 Z 轴切割的最大值：设置后，方块的 Z 轴将会在给定值处结束（默认值则为 0.0，即不偏移）。

## 需要纹理的补丁

* `patch0` - 负向 X 轴侧（西）
* `patch1` - 负向 Y 轴侧（底）
* `patch2` - 负向 Z 轴侧（北）
* `patch3` - 正向 X 轴侧（东）
* `patch4` - 正向 Y 轴侧（顶）
* `patch5` - 正向 Z 轴侧（南）
