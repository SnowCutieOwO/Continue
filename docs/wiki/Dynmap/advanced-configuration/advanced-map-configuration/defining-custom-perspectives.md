# 设置自定义角度

若标准的预设角度无法满足你的需求，你可以自行设置自定义角度。通过自定义角度，用户可以完全开发渲染引擎全部的灵活度与功能性。

自定义角度可通过改变 `perspectives.txt` 下的标准角度定义，或在 `custom-perspectives.txt` 新建（推荐）设置实现。

目前只支持一种角度：IsoHDPerspective 类。这个类定义了一个等距视角，可自定义其方向、角度及比例。标准角度定义结构示例如下：

``` YAML
perspectives:
  - class: org.dynmap.hdmap.IsoHDPerspective
    name: my_custom_perspective
    azimuth: 124
    inclination: 55
    scale: 16
```

等距视角的必选设置如下：
* `name`：角度定义的名称，不可重复。若 custom-lightings.txt 中有自定义角度与标准角度定义中的名称重合，那么对应的标准角度将会被自定义角度设置覆盖。
* `azimuth`：从北侧顺时针起算的地图角度：0 = 正北，90 = 正东，180 = 正南，270 = 正西。可填入任意角度值。
* `inclination`：俯视地图的角度。90 = 垂直朝下，0 = 水平（不可填入）。可填入任意 20 至 90 度间的值。
* `scale`：渲染场景时的缩放或分辨率，单位为每方块边缘像素数。可填入 1 到 64 的值，但 64 会导致地图变得巨大；16 对应标准角度的 hires，8 对应 medres，4 对应使用了非资源包（洞穴、群系、颜色结构等）阴影的 lowres。

除了这些基本的必须选项以外，还有一些额外选项可以进一步修改角度的处理方式：

* `maxiumheight`：若设置，决定渲染方块的最大高度（Minecraft 地图中的 Y 轴）。若小于 127，则以上的所有方块都不会被渲染——会将世界在网页地图中的样子削去一层。可用于显示地下内容。
* `minimumheight`：若设置，决定渲染方块的最小高度（Minecraft 地图中的 Y 轴）。若大于 0，则以下的所有方块都不会背渲染——会将世界在网页地图中的样子削去一层。可用于显示地下内容。
* `fence-to-block-join`：若设置，覆盖 `configuration.txt` 的 `fence-to-block-join` 设置。若为 `true`，则栅栏渲染时会与其他实心方块相连（如同 1.9 之后的栅栏行为）；否则，只与其他栅栏类方块相连。
