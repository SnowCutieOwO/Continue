# 角度预设列表

所有预设角度都可在 `perspectives.txt` 文件中找到。可按需求进一步修改，不过建议将修改或新建角度放入 `custom-perspectives.txt` 中。

完整预设角度如下：

* `default`：默认角度，从东南向（135° 方位角）看向地图，水平朝下 60°（俯视），单方块边缘比例为 4 像素（lowres）。
* `classic`：从东南向（135° 方位角）看向地图，水平朝下 60°（俯视），单方块边缘比例为 1.4 像素。与 KzedMap 相似。
