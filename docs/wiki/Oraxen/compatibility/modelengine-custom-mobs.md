# ModelEngine - 自定义实体
如何合并资源包？

Oraxen 与 ModelEngine 实现各自功能时使用的物品不同，因此可以兼容。据我所知，ModelEngine 使用的是皮革马铠。如果你没有在 Oraxen 配置中使用过它，通常情况下不会产生冲突。

## 如何合并？

打开 ModelEngine 文件夹。其结构如图所示：

打开 `resource pack`（资源包）文件夹：

![](_images/image40.png 'resource pack 文件夹的内容，图片由 @Thew 提供')

复制 assets 文件夹（整个文件夹，不只是里面的文件！），将其放入 `Oraxen/pack` 中，如图所示：
