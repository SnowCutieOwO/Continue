# Hytale
这里是所有支持 PlaceholderAPI 的插件列表。这些插件提供了自己的变量，或是能够解析其他插件的变量。

如果这里没有你的插件，你可以浏览[维基的自述文件](https://github.com/PlaceholderAPI/PlaceholderAPI/blob/wiki/README.md)，通过拉取请求让维基收录。
