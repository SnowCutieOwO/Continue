# 全局地标菜单

在这里你可以找到自定义岛屿地标界面的教程。

## 全局设置

首先，通过 `title`（字符串）设置为菜单赋予自定义标题。之后，你可以自行配置其他选项：`previous-menu`（布尔值）决定是否在关闭菜单后显示上级菜单，`type`（字符串）决定菜单显示的界面类型，`open-sound`（声音格式）可以在打开菜单时播放自定义音效。

::: info

你可以在[这里](https://hub.spigotmc.org/javadocs/bukkit/org/bukkit/event/inventory/InventoryType.html)找到有效的界面类型。

:::

## 排版设置

让我们着手研究排版。排版部分决定了菜单的显示样式。这是一系列字符串，其中的每个字符都代表着菜单中显示的一个按钮。它应当包含一至六行的字符串，每个字符串包含九个字符——空格不算作字符。如果不同格子有两个相同的字符，则这两个格子会显示相同的物品。物品的实际显示内容不在这里配置，而是在 `items` 部分。

## 分页式菜单设置

岛屿地标菜单有一个可配置的额外部分——`visitor-warps`。启用后，以岛屿访客地标的位置代替一般的地标位置。可以使用内建变量 `{1}` 返回地标描述。

这些类型的菜单有四个额外选项：
* `warps` - 代表着岛屿地标的按钮（同样支持 `slots`）。
* `previous-page` - 代表着翻回上一页的按钮。
* `current-page` - 代表着当前页的按钮。
* `next-page` - 代表着翻到下一页的按钮。

## 岛屿地标相关设置

岛屿地标有两个可配置的额外设置。首先是 `time-sort`，代表着点击后会将日志按时间排序的按钮。与之相似的则是 `money-sort`，代表着点击后会将日志按交易数额排序的按钮。只需将代表它们的字符填入排版设置中即可将这些按钮置入菜单。

::: info

如果你不需要这些按钮，只需将它们的设置从配置中删去即可。

:::

## 物品设置

这就是你配置物品的地方。你可以在[这里](index.md#编辑菜单内的物品)找到如何正确配置物品的教程。

### 自定义变量

分页菜单（`slots`、`previous-page` 等）支持嵌入内建变量！

* `slots` - 
  * `{0}` - 岛屿拥有者的名称。
  * `{1}` - 岛屿访客传送点的描述（启用 `visitor-warps` 后有效）。
  * `{2}` - 岛屿拥有的地标数量。
  * `{3}` - 岛屿的名称。
  * `{4}` - 岛屿的等级。
  * `{5}` - 岛屿的等级，按缩写格式显示。`K` 表示千，`M` 表示百万，以此类推。
  * `{6}` - 岛屿的价值。
  * `{7}` - 岛屿的价值，按缩写格式显示。`K` 表示千，`M` 表示百万，以此类推。
  * `{8}` - 岛屿总评分，按数字显示。
  * `{9}` - 岛屿总评分，按星级显示。
* `previous-page`、`next-page` - 
  * `{0}` - 若存在下一页则显示为绿色（`&a`），反之则为红色（`&c`）
* `current-page` -
  * `{0}` - 当前页码

## 菜单示例

这是岛屿地标菜单的示例配置，涵盖了本章节教程提及的大部分技术及功能。

``` YAML
title: '&l岛屿地标'
previous-menu: true

pattern:
  - '@ @ @ @ @ @ @ @ @'
  - '@ @ @ @ @ @ @ @ @'
  - '@ @ @ @ @ @ @ @ @'
  - '@ @ @ @ @ @ @ @ @'
  - '$ $ $ $ $ $ $ $ $'
  - '# # % # * # ^ # #'

warps: '@'
previous-page: '%'
current-page: '*'
next-page: '^'

# 启用后，以访客位置代替地标展示。
# 描述可通过内建变量 `{1}` 返回。
visitor-warps: false

items:
  '@':
    type: SKULL_ITEM
    data: 3
    name: '&e{0} 的岛屿'
    lore:
      - '&7点击浏览岛屿上的所有地标.'
      - '&8>> &7这个岛屿一共有 {2} 个地标.'
  '%':
    type: PAPER
    name: '{0}上一页'
  '*':
    type: DOUBLE_PLANT
    name: '&a当前页'
    lore:
      - '&7第 {0} 页'
  '^':
    type: PAPER
    name: '{0}下一页'
  '$':
    type: STAINED_GLASS_PANE
    data: 15
    name: '&f'

sounds:
  '@':
    type: ORB_PICKUP
    volume: 0.2
    pitch: 0.2
```
