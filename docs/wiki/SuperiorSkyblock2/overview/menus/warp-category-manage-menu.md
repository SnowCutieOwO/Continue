# 地标分类管理菜单

在这里你可以找到自定义设置界面的教程。

## 全局设置

首先，通过 `title`（字符串）设置为菜单赋予自定义标题。之后，你可以自行配置其他选项：`previous-menu`（布尔值）决定是否在关闭菜单后显示上级菜单，`type`（字符串）决定菜单显示的界面类型，`open-sound`（声音格式）可以在打开菜单时播放自定义音效。

菜单标题支持自定义内建变量：

* `{0}` - 返回被编辑图标所属的分类。

::: info

你可以在[这里](https://hub.spigotmc.org/javadocs/bukkit/org/bukkit/event/inventory/InventoryType.html)找到有效的界面类型。

:::

## 排版设置

让我们着手研究排版。排版部分决定了菜单的显示样式。这是一系列字符串，其中的每个字符都代表着菜单中显示的一个按钮。它应当包含一至六行的字符串，每个字符串包含九个字符——空格不算作字符。如果不同格子有两个相同的字符，则这两个格子会显示相同的物品。物品的实际显示内容不在这里配置，而是在 `items` 部分。

## 地标分类管理相关设置

地标分类管理菜单用于管理指定地标分类，有一些必须配置的图标。只需在排版界面中为其分配自定义单字符即可。

|字段|类型|描述|
|---|---|---|
| `category-rename` | 单字符 | 重命名分类的按钮。 |
| `category-icon` | 单字符 | 打开[分类图标编辑菜单](warp-category-icon-edit-menu.md)的按钮。 |
| `category-warps` | 单字符 | 打开分类地标菜单的按钮。 |
| `success-update-sound` | 声音 | 地标分类更新成功后播放的声音。 |

## 菜单示例

这是独特访客菜单的示例配置，涵盖了本章节教程提及的大部分技术及功能。

``` YAML
title: '&l分类: {0}'
previous-menu: true

pattern:
  - '@ @ @ @ @ @ @ @ @'
  - '@ ! @ @ ~ @ @ $ @'
  - '@ @ @ @ @ @ @ @ @'

success-update-sound:
  type: ORB_PICKUP
  volume: 0.2
  pitch: 0.2

category-rename: '!'
category-icon: '~'
category-warps: '$'

items:
  '!':
    type: BOOK
    name: '&6重命名分类'
    lore:
      - '&f '
      - '&f '
      - '&7&o(( &f&o点击&7&o重命名该分类. ))'
  '~':
    type: STONE
    lore:
      - '&f '
      - '&f '
      - '&7&o你可以使用如下内建变量:'
      - '&7&o{0} 返回地标名称.'
      - '&7&o{1} 返回地标位置.'
      - '&7&o{2} 返回地标开放状态.'
      - '&7&o(( &f&o右键点击&7&o编辑图标. ))'
      - '&7&o(( &f&o左键点击&7&o编辑分类格子. ))'
  '$':
    type: ENDER_PEARL
    name: '&6岛屿传送点'
    lore:
      - '&f '
      - '&f '
      - '&7&o(( &f&o点击&7&o编辑分类地标. ))'
```
