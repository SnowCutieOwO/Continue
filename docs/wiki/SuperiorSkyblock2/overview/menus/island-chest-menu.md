# 岛屿仓库菜单

在这里你可以找到自定义岛屿仓库界面的教程。

## 全局设置

首先，通过 `title`（字符串）设置为菜单赋予自定义标题。之后，你可以自行配置其他选项：`previous-menu`（布尔值）决定是否在关闭菜单后显示上级菜单，`type`（字符串）决定菜单显示的界面类型，`open-sound`（声音格式）可以在打开菜单时播放自定义音效。

::: info

你可以在[这里](https://hub.spigotmc.org/javadocs/bukkit/org/bukkit/event/inventory/InventoryType.html)找到有效的界面类型。

:::

## 排版设置

让我们着手研究排版。排版部分决定了菜单的显示样式。这是一系列字符串，其中的每个字符都代表着菜单中显示的一个按钮。它应当包含一至六行的字符串，每个字符串包含九个字符——空格不算作字符。如果不同格子有两个相同的字符，则这两个格子会显示相同的物品。物品的实际显示内容不在这里配置，而是在 `items` 部分。

## 分页式菜单设置

岛屿地标菜单有一个可配置的额外部分——`visitor-warps`。启用后，以岛屿访客地标的位置代替一般的地标位置。可以使用内建变量 `{1}` 返回地标描述。

这些类型的菜单有四个额外选项：
* `slots` - 代表着箱子页面的按钮。
* `previous-page` - 代表着翻回上一页的按钮。
* `current-page` - 代表着当前页的按钮。
* `next-page` - 代表着翻到下一页的按钮。

::: info

岛屿仓库菜单支持 `skin-one-item` 选项——当岛屿仓库只有一页时，箱子界面会直接打开而非先进入菜单。

:::

## 物品设置

这就是你配置物品的地方。你可以在[这里](index.md#编辑菜单内的物品)找到如何正确配置物品的教程。

### 仓库分页物品

箱子分页按钮（`slots` 字符）与一般的物品格式有所不同，有着部分必须设置的内容：

|字段|类型|描述|
|---|---|---|
| `valid-page` | 配置部分（物品） | 有可用页面时显示的按钮样式。 |
| `invalid-page` | 配置部分（物品） | 无可用页面时显示的按钮样式。 |

### 自定义变量

`valid-page` 物品支持自定义变量！
* `{0}` - 页码。
* `{1}` - 当前页里的槽位数量。
分页物品也支持自定义变量：
* `previous-page`、`next-page` - 
  * `{0}` - 若存在下一页则显示为绿色（`&a`），反之则为红色（`&c`）
* `current-page` -
  * `{0}` - 当前页码

## 菜单示例

这是岛屿地标菜单的示例配置，涵盖了本章节教程提及的大部分技术及功能。

``` YAML
title: '&l岛屿仓库'
previous-menu: true

pattern:
  - '# # # # # # # # #'
  - '# $ @ @ @ @ @ $ #'
  - '# $ @ @ @ @ @ $ #'
  - '# $ @ @ @ @ @ $ #'
  - '# $ @ @ @ @ @ $ #'
  - '# # % # * # ^ # #'

slots: '@'
previous-page: '%'
current-page: '*'
next-page: '^'

items:
  '@':
    valid-page:
      type: STORAGE_MINECART
      name: '&e第 {0} 页'
      lore:
        - '&e大小: &7{1}'
    invalid-page:
      type: MINECART
      name: '&f '
  '%':
    type: PAPER
    name: '{0}上一页'
  '*':
    type: DOUBLE_PLANT
    name: '&a当前页'
    lore:
      - '&7第 {0} 页'
  '^':
    type: PAPER
    name: '{0}下一页'
  '#':
    type: RAILS
    name: '&f '

sounds:
  '@':
    type: CHEST_OPEN
    volume: 0.8
    pitch: 1
```
