# 升级菜单

在这里你可以找到自定义升级界面的教程。

## 全局设置

首先，通过 `title`（字符串）设置为菜单赋予自定义标题。之后，你可以自行配置其他选项：`previous-menu`（布尔值）决定是否在关闭菜单后显示上级菜单，`type`（字符串）决定菜单显示的界面类型，`open-sound`（声音格式）可以在打开菜单时播放自定义音效。

::: info

你可以在[这里](https://hub.spigotmc.org/javadocs/bukkit/org/bukkit/event/inventory/InventoryType.html)找到有效的界面类型。

:::

## 排版设置

让我们着手研究排版。排版部分决定了菜单的显示样式。这是一系列字符串，其中的每个字符都代表着菜单中显示的一个按钮。它应当包含一至六行的字符串，每个字符串包含九个字符——空格不算作字符。如果不同格子有两个相同的字符，则这两个格子会显示相同的物品。物品的实际显示内容不在这里配置，而是在 `items` 部分。

## 升级部分

除了普通的菜单部分，升级菜单还有一个 `upgrades` 部分，这里可以配置所有按钮。每个升级都有自己的子配置部分，它们的键名来自于 `upgrades.yml`（升级配置文件）。

每个升级部分都有一个对应单字符升级按钮的 `item` 设置部分。除此之外，每级升级都有一个子配置，其等级数字作为键名。每个等级部分都有如下字段：

|字段|类型|描述|
|---|---|---|
| `has-next-level` | 配置部分（物品） | 当有下一级升级可用时显示的物品。 |
| `no-next-level` | 配置部分（物品） | 当无下一级升级时显示的物品。 |

这两个物品都可以设置 `sound`（点击对应状态物品时播放）及 `commands` 列表。

### 自定义变量

升级物品（`slots`、`previous-page` 等）支持嵌入内建变量！

* `{0}` - 下一级的价格。
* `{1}` - 下一级的价格，以逗号分隔。
* `{2}` - 下一级的价格，按格式显示，`K` 代表千，`M` 代表百万。

## 菜单示例

这是升级菜单的示例配置，涵盖了本章节教程提及的大部分技术及功能。

``` YAML
title: '&l岛屿升级'
previous-menu: true

pattern:
  - '$ $ $ $ $ $ $ $ $'
  - '# # @ # % # ^ # #'
  - '# # # ! # + # # #'
  - '# # * # ~ # & # #'
  - '$ $ $ $ $ $ $ $ $'

items:
  '$':
    type: STAINED_GLASS_PANE
    data: 15
    name: '&f'

upgrades:
  hoppers-limit:
    item: '@'
    '1':
      has-next-level:
        type: HOPPER
        name: '&d&l漏斗增量 &a(可升级)'
        lore:
          - '&7'
          - '&d下一等级: &e2'
          - '&7'
          - '&7购置漏斗升级'
          - '&7可提升岛屿的'
          - '&7漏斗放置上限.'
          - '&7'
          - '&d数量: &f16x 漏斗'
          - '&d价格: &f$1,000,000'
          - '&7'
          - '&a点击购买这个升级.'
        sound:
          type: ORB_PICKUP
          volume: 0.2
          pitch: 0.2
      no-next-level:
        type: HOPPER
        name: '&d&l漏斗增量 &c(不可用)'
        lore:
          - '&7'
          - '&d下一等级: &e2'
          - '&7'
          - '&7购置漏斗升级'
          - '&7可提升岛屿的'
          - '&7漏斗放置上限.'
          - '&7'
          - '&d数量: &f16x 漏斗'
          - '&d价格: &f$1,000,000'
          - '&7'
          - '&c你不能购买这个升级.'
    '2':
      has-next-level:
        # ... 与 1 级格式相同 ...
      no-next-level:
        # ... 与 1 级格式相同 ...
  # ... 更多升级 (crop-growth, spawner-rates, mob-drops, members-limit,
  #     border-size, generator-rates, minecarts-limit) 格式保持一致 ...
```
