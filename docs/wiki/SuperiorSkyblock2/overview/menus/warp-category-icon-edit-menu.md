# 地标分类图标编辑菜单

在这里你可以找到自定义设置界面的教程。

## 全局设置

首先，通过 `title`（字符串）设置为菜单赋予自定义标题。之后，你可以自行配置其他选项：`previous-menu`（布尔值）决定是否在关闭菜单后显示上级菜单，`type`（字符串）决定菜单显示的界面类型，`open-sound`（声音格式）可以在打开菜单时播放自定义音效。

菜单标题支持自定义内建变量：

* `{0}` - 返回被编辑图标所属的分类。

::: info

你可以在[这里](https://hub.spigotmc.org/javadocs/bukkit/org/bukkit/event/inventory/InventoryType.html)找到有效的界面类型。

:::

## 排版设置

让我们着手研究排版。排版部分决定了菜单的显示样式。这是一系列字符串，其中的每个字符都代表着菜单中显示的一个按钮。它应当包含一至六行的字符串，每个字符串包含九个字符——空格不算作字符。如果不同格子有两个相同的字符，则这两个格子会显示相同的物品。物品的实际显示内容不在这里配置，而是在 `items` 部分。

## 地标分类图标编辑相关设置

地标分类图标编辑菜单用于编辑指定地标分类的图标，有一些必须配置的图标。只需在排版界面中为其分配自定义单字符即可。

|字段|类型|描述|
|---|---|---|
| `icon-type` | 单字符 | 修改图标物品的按钮。 |
| `icon-rename` | 单字符 | 修改图标名称的按钮。 |
| `icon-relore` | 单字符 | 修改图标描述的按钮。 |
| `icon-confirm` | 单字符 | 确认上述修改的按钮。 |
| `icon-slots` | 单字符 | 用作修改后图标预览的按钮。 |

## 菜单示例

这是独特访客菜单的示例配置，涵盖了本章节教程提及的大部分技术及功能。

``` YAML
title: '&l分类: {0}'
previous-menu: true

pattern:
  - '@ @ @ @ @ @ @ @ @'
  - '@ ! @ @ @ @ @ ~ @'
  - '@ @ @ @ ^ @ @ @ @'
  - '@ $ @ @ @ @ @ % @'
  - '@ @ @ @ @ @ @ @ @'

icon-type: '!'
icon-rename: '~'
icon-relore: '$'
icon-confirm: '%'
icon-slots: '^'

items:
  '!':
    type: DIAMOND
    name: '&6设置类型'
    lore:
      - '&f '
      - '&f '
      - '&7&o(( &f&o点击&7&o编辑物品类型. ))'
  '~':
    type: ANVIL
    name: '&6设置名称'
    lore:
      - '&f '
      - '&f '
      - '&7&o(( &f&o点击&7&o编辑物品名称. ))'
  '$':
    type: PAPER
    name: '&6设置描述'
    lore:
      - '&f '
      - '&f '
      - '&7&o(( &f&o点击&7&o编辑物品描述. ))'
  '%':
    type: EMERALD
    name: '&6保存改动'
    lore:
      - '&f '
      - '&f '
      - '&7&o(( &f&o点击&7&o确认并保存改动. ))'
  '^':
    type: STONE

sounds:
  '%':
    type: ORB_PICKUP
    volume: 0.2
    pitch: 0.2
```
