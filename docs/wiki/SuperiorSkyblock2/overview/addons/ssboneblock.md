# SSBOneBlock

支持 SuperiorSkyBlock2 的单方块空岛！

*原视频来自 Youtube，本维基不在此列出。*

这个附属模块会在新空岛创建时生成一个“魔法单方块”。

## 设置单方块

使用单方块拓展时，仍需配置 SuperiorSkyblock2 本体。这表示你得修改你的结构（你肯定不想要在单方块空岛上出现正常的空岛结构吧？），以及其他自定义配置，使得它们符合你预期的单方块空岛体验。结构中心的方块即为无尽单方块（单方块空岛的“核心”），因此创建新结构的时候需要注意这点。

::: info

玩家还是需要通过 `/is create <名称> [结构]` 命令创建自己的单方块空岛——可以在配置里修改。

:::
