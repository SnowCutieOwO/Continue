# 更新 Towny

本章将会讲述如何从旧版 Towny 更新。

## 更新步骤

1. 关闭服务器。
2. 备份整个服务器！
  * 如果你以配置文件形式存储 Towny 数据，Towny 会自行备份（不包含世界内的方块！仍需要完整备份。）
  * 可能需要从 `plugins\towny\backups\` 文件夹中找到最新的 .zip 备份数据并将其移动到其他安全的地方。
3. 下载 Towny_Advanced.zip，并解压获得 .jar 文件，将其放入 plugins 文件夹中。
  * 确保你已经删除了插件文件夹中安装的旧版 Towny。
4. 浏览更新日志或发行版页面获悉新内容。
  * 更新日志中包含了需要手动更改的内容（不过现在比较少见。）
  * 其他配置改动（如新设置）会自动加入文件。
    * 新增的设置通常为其默认值。
  * **无需每次更新时都删除/编辑 Towny 的配置文件。**
5. 启动服务器。
6. 按需调整新增配置。
7. 关闭服务器。

## 特殊操作步骤

* 若从低于 0.79.0.0 的版本更新：
  * config.yml 的 chat 部分已经独立为新文件 channels.yml。只需编辑新文件中的设置即可。
* 若从低于 0.82.0.0 的版本更新：
  * Towny 新增了 TownyPerms。新增了一个位于 townysettings 下的 townyperms.yml 文件，首次启动服务器时自动生成。
    * 这个模块向服务器添加了城镇及国家等级，管理员可手动指定各个等级的权限（游民、居民、城镇拥有者、国家领袖等）。除此之外，管理员也可以创建自定义等级，设置自定义权限。设置为助理的玩家会失去当前等级，需要重新为其分配权限。
