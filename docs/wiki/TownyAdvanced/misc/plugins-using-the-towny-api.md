## 使用了 Towny API 的插件

如下插件通过 Towny API 与 Towny 兼容或联动。

* [TownyWars](https://www.spigotmc.org/resources/townywars.80038/) - 适用于 Towny 的简单战争插件。（已停更）（建议使用 [SiegeWar](https://github.com/TownyAdvanced/SiegeWar)/[FlagWar](https://github.com/TownyAdvanced/FlagWar)/[EventWar](https://townyadvanced.github.io/eventwar.html)）

* [Lockette](http://www.palmergames.com/file-repo/Lockette/1.7.12/) - Towny 可以在 `/plot clear` 期间清除地皮上的牌子锁。

* [ChestShop](https://www.spigotmc.org/resources/chestshop.51856/) - 只允许在 Towny 的商店地皮上创建箱子商店。需要安装 [ChestShop-Towny](https://github.com/TownyAdvanced/ChestShop-towny/releases)。

* [ecoCreature](http://dev.bukkit.org/bukkit-plugins/ecocreature/) - 根据所在城镇提升或降低杀怪获得的钱。

* [Faction Mobs](http://dev.bukkit.org/bukkit-plugins/faction-mobs) - 这个插件（原名为 Towny Mobs）晕奴性你生成指定阵营的怪物。它们会攻击敌对阵营的玩家或怪物。

* [Dynmap-Towny](https://github.com/TownyAdvanced/Dynmap-Towny/releases) - 这个插件提供了一种在 Dynmap 地图上显示 Towny 城镇及国家的方式。需要同时安装 Dynmap 和 Towny Advanced。除此之外它也直接使用了 Towny API。

* [MapTowny](https://github.com/TownyAdvanced/MapTowny) - 这个插件提供了 Dynmap/BlueMap/SquareMap/Pl3xMap 支持，同时为开发者提供了一个更新更好的 API。

* [McMMO-Towny](https://github.com/TownyAdvanced/mcMMO-Towny/releases/tag/1.0.1) - 允许在 Towny 城镇中获得 McMMO 的经验。

* [Trails](http://dev.bukkit.org/bukkit-plugins/trails/) - Trails 是一款非常契合 RPG 风格的插件，可以让玩家频繁走过的路从泥土变成石头铺就。可以限制为只在郊区中生效。

* [GChat](http://www.spigotmc.org/resources/gchat-free-towny-version.6291/) - JSON 风格的聊天插件，兼容 Towny Advanced。插件以 JSON 格式为服主提供了集美观与功能于一身的聊天栏。这是一个轻量化的插件，能也只能与 Towny Advanced 搭配使用，足以替代默认的 TownyChat.jar。

* [TownyGUI](https://www.spigotmc.org/resources/townygui.35745/) - 为 Towny 的命令设计的菜单插件，快去看看吧！

* [TownyFlight](https://www.spigotmc.org/resources/townyflight.50360/) - 一款免费的飞行插件，作者是 LlmDl。

* [Towny-TNE](https://www.spigotmc.org/resources/towny-tne.71240/) - 将 Towny 位置与 The New Economy 特性兼容的插件，作者是 LlmDl。

* [RPG Leveled Mobs](https://www.spigotmc.org/resources/rpg-leveled-mobs.71301/) - 一款为怪物带来了 RPG 等级的插件，作者是 iomatix。

* [HuntPlayer](https://www.spigotmc.org/resources/huntplayer.71789/) - 揭示其他玩家信息的插件。包括 Towny 地皮。适用于 PVP 服务器，作者是 LlmDl。

* [TownyMarket](https://www.spigotmc.org/resources/townymarket-sell-and-buy-towny.71786/) - 允许将城镇在服务器上挂售，作者是 Dzirt。

* [TownyLocations](https://www.spigotmc.org/resources/townylocations.76778/) - 允许浏览其他玩家地皮的插件，若有权限还可传送。

* [DiscordTownyLink](https://www.spigotmc.org/resources/discordtownylink.78179/) - 通过 Discord 管理玩家职位，作者是 Coco10203。

* [CropClick](https://www.spigotmc.org/resources/cropclick.69480/) - 允许玩家点击收割农作物。这个插件兼容 Towny 保护区域内玩家的交互，作者是 BakuPlayz。

- A plugin that lets players click crops and receive the drops. CropClick uses Towny to allow/deny players to click crops, by .

* [TownyMenu](https://www.spigotmc.org/resources/towny-menu-update.103260/) - 这是一个简单的插件，旨在为 Towny 添光增色。有了这个插件，你就不再需要输入冗长枯燥的命令。从城镇权限、税收、居民等级，再到地皮价格与类型都可以在简单、强引导性的菜单中完成。

* [BlueMap-Towny](https://github.com/Chicken/BlueMap-Towny) - 在你的 [BlueMap](https://www.spigotmc.org/resources/bluemap.83557/) 上显示 Towny 的城镇！

* [TownyMissions](https://www.spigotmc.org/resources/townymission-a-must-have-addition-to-towny-servers.94472/) - 这个任务插件可以在服务器上产生良性竞争。

* [Towny-Info](https://github.com/honnisha/towny-info) - 基于告示牌显示城镇与国家排行榜，拥有点击传送等多种功能，作者是 Honnisha。

* [NotQuests](https://www.spigotmc.org/resources/1-17-x-1-18-x-notquests-%E2%9A%A1-solid-quest-system-%E2%9C%85.95872/) - 有 Towny 联动的任务插件（目前，可以要求玩家处于某个国家中才可接取任务。允许你制作不同国家的阵营任务）

* [TownyElections](https://github.com/lofi-enjoyer/TownyElections) - 觉得默认的 Towny 机制太专治？这个选举插件适合你！

* [TownyWild](https://www.spigotmc.org/resources/townywild.107829/) - 离开 Towny 城镇时对郊区进行限时保护。

* [WorldDynamics Engine](https://github.com/thatguycy/WorldDynamics-Engine) - 这个插件是一款精妙的角色扮演与特色插件，专为地缘政治服务器打造。允许玩家沉浸于动态的政治地形、资源管理、参与外交，用他们的想法改变世界。

* [TheGoldEconomy](https://www.spigotmc.org/resources/thegoldeconomy-1-18-1-20-6-simple-gold-based-economy.102242/) - 一款简单的基于金锭的物品经济插件。

## 使用了元数据的插件

* [Floristics](https://github.com/JayAvery/floristics) - 为 Minecraft 添加了自然植物生长的插件，使用了 Towny 的元数据限制或阻止城镇内的植被生长。

* [TownyMusic](https://www.spigotmc.org/resources/townymusic.106049/) - 允许利用 [NoteBlockAPI](https://www.spigotmc.org/resources/noteblockapi.19287/) 在城镇内播放音乐。

* [Towny Spawn Menu](https://www.spigotmc.org/resources/towny-spawn-menu.105225/) - 添加了城镇菜单，允许浏览或传送至不同的城镇。

* [Quarters](https://modrinth.com/plugin/quarters) - 允许城镇拥有者在城镇中设置立体的“居住空间”，可以由玩家租用。

* [TownyPersistentToggle](https://github.com/SulkyWhale/TownyPersistentToggle) - 保持 Towny 居民的模式及相关 HUD 界面在服务器重启或玩家退出时保持不变的插件，利用了 Towny 元数据存储不同玩家的界面相关设置。
