# 支持

在 Towny Wiki 上找到的文档会随着插件迭代而更新。如果你正在使用开发构建，默认视作你已经读过了更新日志，并已经了解了先前发行版的更新内容。

一些值得一读的部分：

* 安装 Towny
* Towny 的运行原理

你可以在 Github 上的议题追踪器[提交漏洞](https://github.com/TownyAdvanced/Towny/issues/new?assignees=&labels=&template=bug_report.md&title=)、[建议新功能](https://github.com/TownyAdvanced/Towny/issues/new?assignees=&labels=&template=feature_request.md&title=Suggestion%3A+)或者[问问题](https://github.com/TownyAdvanced/Towny/discussions/new?category=Q-A)。
