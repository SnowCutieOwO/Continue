# 调色板（Palette）

表示对[调色板](../config-files/palette.md)配置的引用。

`Palette` 通过引用调色板的 ID 定义。例如，一个 ID 为 `GRASS_MIX` 的 `PALETTE` 配置在 `palette` 参数中引用的格式如下：

``` YAML
palette: GRASS_MIX
```
