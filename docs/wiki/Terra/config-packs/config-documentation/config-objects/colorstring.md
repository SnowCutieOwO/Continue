# 颜色字符串（ColorString）

\* 配置对象需要 `library-image` 附属才可使用

表示颜色的字符串。

## 用途

有 2 个参数用到：

* ColorSampler 中的 COLOR：

  <badge type="info" text="color" /> [颜色字符串](colorsampler.md) - 输出的颜色。

* BiomeColorMapping 中的 MAP:

  <badge type="info" text="map" /> [映射表](map.md)<[颜色字符串](colorstring.md)，[群系](../../config-documentation/config-files/biome.md)>
