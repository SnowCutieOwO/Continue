# Terra API

Terra 实现了一个高级的通用世界生成 API，可以通过附属拓展配置结构。实际上，所有 Terra 的默认配置都通过拓展实现。

## 附属

附属即为 Terra 的拓展。对它本身来说，Terra 只是一个带有平台实现的 API，任何功能的实现都依赖于附属和配置。附属创建配置结构，而配置利用它们实现功能。

有些时候，一个附属可能会绕过配置实现某个功能，但我们仍然鼓励用户通过配置实现功能。
