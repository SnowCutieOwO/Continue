# 前言

MMOInventory 是一款配置简单、易于上手且功能强大的自定义界面插件，允许实现类似 WynnCraft 风格的装备栏（原版界面）及其他 RPG 游戏的自定义装备界面。

此次翻译耗时三天，是 MMO 系列翻译计划（也是维基第三次大更新）的一部分。余下作品（MMOItems 之类）会在年末放出。

没有什么特别想说的话，只是想翻译了，然后就产出一点作品，再去忙自己的其他事。

值得一提的是，MMO 系列的插件维基与 AuraSkills 一样，都使用了 VitePress 作为维基框架，这无疑方便了许多。即便如此，我也还是喜欢直接看页面而不是去翻 Github 托管的页面源代码，当然是因为*懒*。
