# 🔌 安装教程

* 下载并安装 [MythicLib](https://www.spigotmc.org/resources/mmolib-mythiclib.90306/)。这是本插件的唯一硬依赖。
* 下载 MMOInventory 的 .jar 格式文件，将其放入 `/plugins` 文件夹。
* 如果你的服务器上还有 MMOItems，强烈建议你读一读[这个章节](../compatibility/mmoitems.md)。
* 下载默认的 MMOInventory 服务器资源包，在客户端应用它（或者通过其他插件与现有的资源包合并发送）。

|资源包适用版本|下载链接|
|---|---|
| 1.14 至 1.21.2 | [谷歌 Dropbox](https://www.dropbox.com/s/1lftxmzh0q4b5yu/mmoinv_rp_3.zip?dl=1) |
| 1.21.4 以上 | [Gitlab](https://gitlab.com/phoenix-dvpmt/mmoinventory-default-resource-pack) |
