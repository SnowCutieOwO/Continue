# 💾 命令列表

|命令|描述|
|---|---|
| `/mmoinv reload` | 重载插件 |
| `/mmoinv export-data` | 将玩家数据从 YAML 文件导出到 SQL 数据库 |
| `/mmoinv open <界面> <拥有者>` | 让指定玩家打开界面 |
| `/mmoinv open <界面> <拥有者> <玩家名称> <允许编辑>` | 让指定玩家打开界面，`can_edit` 标签可设置为`true`（允许装备或取下物品）或 `false`（不允许装备或取下物品） |
| `/mmoinv inspect <界面> <拥有者>` | 浏览指定玩家的自定义界面 |

如上命令还有这些别称：`/mmoinv`、`/rpginv`、`/rpginventory`。
