# 初次使用

## 下载

**ExcellentEnchants** 可在如下平台免费获取：

* [SpigotMC](https://www.spigotmc.org/resources/61693/)
* [Modrinth](https://modrinth.com/plugin/excellentenchants)
* [Hangar](https://hangar.papermc.io/NightExpress/ExcellentEnchants)

## 安装

1. 关闭服务器。
2. 下载 [NightCore](https://nightexpressdev.com/nightcore/)——一款轻量化的前置库插件，**ExcellentEnchants** 需要它才可以运行。
3. 从对应平台下载 [ExcellentEnchants](#下载)。
4. 将 `nightcore.jar` 与 `ExcellentEnchants.jar` 放入服务器的 **/plugins** 文件夹。确保里面没有它们的旧版本。
5. 启动服务器。
6. 检查控制台，确保这两个插件没有任何报错。
7. 可以使用了！
