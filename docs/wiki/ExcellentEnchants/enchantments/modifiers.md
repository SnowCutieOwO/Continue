# 修饰符

在 ExcellentEnchants 的配置文件夹中，你可以看见多个“修饰符”设置，参数大致如下：

* **基数（Base）** - 修饰符的初始值。
* **每级（Per Level）** - 每级附魔提供的增益数值。
* **上限（Capacity）** - 可能的最大值。
* **行为（Action）** - 为**基数**和**每级**值进行指定的计算操作。
  可填入：`ADD`（叠加）、`MULTIPLY`（相乘）。

**修饰符**允许的值会根据附魔等级动态调整。

它可以是这样：

* **基数**：1.0
* **每级**：0.5
* **上限**：3
* **行为**：叠加

## 公式

* 叠加（ADD）：
  $result = base + ( per\_level \times level )$
* 相乘（MULTIPLY）：
  $result = base \times ( per\_level \times level )$

## 示例值

|附魔等级|等级奖励|最终值|
|---|---|---|
|I|$0.5 \times 1 = 0.5$|$1.0 + 0.5 = 1.5$|
|II|$0.5 \times 2 = 1.0$|$1.0 + 1.0 = 2.0$|
|III|$0.5 \times 3 = 1.5$|$1.0 + 1.5 = 2.5$|
|IV|$0.5 \times 4 = 2.0$|$1.0 + 2.0 = 3.0$|
|V|$0.5 \times 5 = 2.5$|$1.0 + 2.5 = 3.5 \to 3.0$|

::: info

最终值受**上限**参数影响。

:::
