### 参与翻译的插件&模组

> [!NOTE]
> 标“内置(Initial)”的插件名称表明简体中文已内置在这些插件的语言文件中。

> [!NOTE]
> 部分无法提交为简体中文的配置文件存储在本仓库的 `unofficial-translations` 文件夹下，有需要可自行存取。

> [!NOTE]
> 由于插件配置的特殊性，适用于维基的计数工具并不能在此直接使用，因此字数统计可能略有偏差。
