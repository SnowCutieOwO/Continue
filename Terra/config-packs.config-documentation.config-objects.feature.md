# 地物（Feature）

表示对[地物](config-packs.config-documentation.config-files.feature.md)配置的引用。

`Feature` 通过引用调色板的 ID 定义。例如，一个 ID 为 `OAK_TREES` 的 `FEATURE` 配置在 `feature` 参数中引用的格式如下：

``` YAML
feature: OAK_TREES
```

## 用途

只有一个参数用到：

* BIOME 中的 base：
