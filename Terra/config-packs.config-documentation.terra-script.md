# TerraScript

## TerraScript 是什么？

这是一种自定义脚本语言，格式类似于 JavaScript，用于设计自定义[结构](config-packs.config-documentation.config-objects.structure.md)。它易于学习、便于使用且功能强悍。

你可以利用 TerraScript 创造许多东西，从诸如各种形状的树与岩石的逐步生成建筑，到诸如地牢与矿井的复杂结构排版。
