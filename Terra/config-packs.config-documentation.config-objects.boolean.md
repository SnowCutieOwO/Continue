# 布尔值（Boolean）

为 `true` 或 `false` 的值。

见“[在配置中定义数据](config-packs.config-development.defining-data-in-configs.md)”了解详情。

## 用途

有 14 个参数用到：

* NoiseSampler 中的 DISTANCE:

<badge type="tip" text="normalize" /> [布尔值](config-packs.config-documentation.config-objects.boolean.md) - 若设置为 true，返回值的范围将会被约束在 `[-1, 1]`，否则返回原距离。

* BIOME 中的 base:

<badge type="tip" text="carving.update-palette" /> [布尔值](config-packs.config-documentation.config-objects.boolean.md)

* Image 中的 STITCHED_BITMAP:

<badge type="tip" text="zero-indexed" /> [布尔值](config-packs.config-documentation.config-objects.boolean.md)

* NoiseSampler 中的 CHANNEL:

<badge type="tip" text="normalize" /> [布尔值](config-packs.config-documentation.config-objects.boolean.md) - 是否将通道约束在 [-1, 1] 的范围中。

* pack.yml 中的 base:

<badge type="tip" text="images.cache.load-on-use" /> [布尔值](config-packs.config-documentation.config-objects.boolean.md)

* SCATTERED_ORE 中的 base:

<badge type="tip" text="physics" /> [布尔值](config-packs.config-documentation.config-objects.boolean.md)

* NoiseSampler 中的 GABOR:

<badge type="tip" text="isotropic" /> [布尔值](config-packs.config-documentation.config-objects.boolean.md)

* Image 中的 BITMAP:

<badge type="tip" text="zero-indexed" /> [布尔值](config-packs.config-documentation.config-objects.boolean.md)

* NoiseSampler 中的 DISTANCE_TRANSFORM:

<badge type="tip" text="invert-threshold" /> [布尔值](config-packs.config-documentation.config-objects.boolean.md)

* Locator 中的 ADJACENT_PATTERN:

<badge type="tip" text="match-all" /> [布尔值](config-packs.config-documentation.config-objects.boolean.md)

* ORE 中的 base:

<badge type="tip" text="physics" /> [布尔值](config-packs.config-documentation.config-objects.boolean.md)

* NoiseSampler 中的 CHANNEL:

<badge type="tip" text="premultiply" /> [布尔值](config-packs.config-documentation.config-objects.boolean.md) - 是否将通道与 alpha 通道值相乘。

* NoiseSampler 中的 DISTANCE_TRANSFORM:

<badge type="tip" text="clamp-to-max-edge" /> [布尔值](config-packs.config-documentation.config-objects.boolean.md)

* BiomeColorConverter 中的 EXACT:

<badge type="tip" text="ignore-alpha" /> [布尔值](config-packs.config-documentation.config-objects.boolean.md)
